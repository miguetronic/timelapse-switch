Timelapse Switch is made by **Miguetronic** (Miguel Parra): open source tools, built carefully.

## License

GPL-2.0-or-later, like OBS Studio. You can use it, study it, share it and change it; changes you share must keep the same freedoms. The source code is on [GitHub](https://github.com/miguetronic/timelapse-switch).

## How it is made

The code is written largely with the help of an AI coding assistant (Claude, by Anthropic), and every change is reviewed by the maintainer. It follows strict, machine-checked coding rules based on NASA/JPL's "The Power of Ten", and it is tested in a real OBS on Linux, with automatic checks of length, sync, rhythm, silence, chapters and pauses.

## Privacy

The plugin sends nothing over the internet. This website uses no cookies, no analytics and no third-party scripts.
