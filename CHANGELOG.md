## [Unreleased]

### Added

- Project skeleton from the official OBS plugin template (obs-plugintemplate, commit 3e7d7ac).
- Strict build: pedantic compiler warnings with zero tolerance, clang-tidy and the GCC analyzer, all run by `tools/check.sh`.
- Coding rules based on "The Power of Ten" (G. J. Holzmann, NASA/JPL), adapted to an OBS plugin.
- Documentation: architecture, requirements, decisions, quality and traceability, building, and the UX and installation specification.
